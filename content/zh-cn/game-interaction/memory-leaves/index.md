## 项目概述

**面向哀伤支持的拼贴式游戏化日记入口研究** 是我在乌特勒支大学完成的硕士论文研究。项目关注哀伤反思过程中用户可能难以开始表达的问题，探索文本书写与拼贴式游戏化两种日记入口，如何在不同反思任务下支持用户开始回忆、组织想法并表达个人感受。

我使用 Unity 与 C# 独立开发了跨平台研究原型，并设计了一项 2×2 组间用户实验，通过量化与质性数据分析比较不同日记入口下的用户体验。项目现已完成，完整论文已收录于乌特勒支大学论文库：[点击跳转](https://studenttheses.uu.nl/items/3477a918-47b1-4887-b57d-fcef7181da46)
